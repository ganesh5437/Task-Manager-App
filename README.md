# Task Manager App

Full-stack task management application with decoupled client/server architecture.

## Features
- REST API for task creation, updates, deletion
- Persistent storage with MongoDB
- Responsive UI for real-time task tracking and status management

## Tech Stack
**Frontend:** React.js
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Deployment:** Render
